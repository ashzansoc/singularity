## Enablement (all modes)

Default **ON**. Coverage:

- **Agent / Ask / Edit** — `maybeEnrichMessagesWithPromptEngine` always ingests + injects Project Context (even if Prompt Engine compile is off)
- **DAG / Runtime tool** — `singularity.ai.runRuntime` auto-attaches `structuredContext`
- **Complete** — prefixes structured context into the completion prompt
- **UI** — Project Context panel

Disable with `singularity.ai.contextEngine.enabled=false` or `SINGULARITY_CONTEXT_ENGINE=false`.

## Architecture

```
User message → relevance gate → ContextExtractor (LangExtract sidecar | heuristic fallback)
  → merge/conflict/supersede → .singularity/project-context/
  → getRelevant(task) → planner / workers / verifier checklist
```

Rest of Singularity never imports LangExtract directly.

## LangExtract Provider

- Package: `langextract[openai]==1.6.0`
- Bridge: Python stdio sidecar + `LangExtractContextExtractor`
- Fallback: `HeuristicContextExtractor` (offline / circuit open / API failure)

## Model Used

Configurable via `SINGULARITY_CONTEXT_MODEL` (default `gemini-2.0-flash`). Benchmarks in CI use the heuristic extractor (no live LLM).

## Database Changes

None (Supabase unchanged). Persistence is workspace JSON under `.singularity/project-context/` with version snapshots.

## Token Reduction (measured, heuristic extractor)

From `benchmarks/context-engine/METRICS.json` (generated by unit benchmark):

| Scenario | Raw tokens | Retrieved tokens | Reduction |
|----------|------------|------------------|-----------|
| short_project | 710 | 97 | 86.3% |
| requirement_change | 698 | 75 | 89.3% |
| conflicting_instructions | 403 | 46 | 88.6% |

Notes:

- These compare **full Project State JSON** vs **task-filtered prompt block**, not full agent conversations.
- LangExtract itself costs extraction tokens when enabled; the win is avoiding rediscovery on every agent call.
- Live LLM extraction cost was not measured in this environment (no API key required for CI).
- Requirement change scenario correctly recorded `superseded: 1`.

## Latency Impact

- Relevance skip path: negligible.
- Heuristic extract + merge + disk save: typically <20ms in unit tests.
- LangExtract sidecar: depends on provider; Node client timeout default 60s with circuit breaker after 3 failures.

- Sidecar delta mapping smoke test (Python)
- Full `npm run test:packages` + `typecheck:packages` + extension esbuild: pass

## Known Limitations

- Default feature flag is **off** (`SINGULARITY_CONTEXT_ENGINE=false`).
- Live LangExtract e2e requires Python + API key + installed `langextract`.
- Document/PDF parsing is text-in only (caller supplies extracted text).
- Requirement verifier is LLM checklist-based; tool verifier unchanged as primary gate.
- Hash/keyword retrieval, not remote embeddings.
