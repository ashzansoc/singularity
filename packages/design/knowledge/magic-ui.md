# Magic UI — Animated UI

Best used for: marquees, animated beams, shimmer buttons, bento grids, number tickers.

## Patterns
- Micro-interactions on CTAs and feature grids.
- Keep animation intentional (2–3 motions per surface), not decorative noise.
- Compose with shadcn primitives underneath.

## Do
- Use for SaaS marketing sections and feature showcases.
- Prefer CSS + Motion over canvas unless needed.

## Don't
- Don't animate layout thrashing (width/height) on every hover in dense app UIs.
