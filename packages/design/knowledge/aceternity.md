# Aceternity-style — Premium visual effects

Best used for: heroes, spotlights, beams, bento grids, glowing cards, textured backgrounds.

## Patterns
- Layer Framer Motion with Tailwind; keep motion 150–250ms for chrome, longer only for hero entrance.
- Effects should support the brand composition — never cover the headline with floating badges.
- Prefer full-bleed atmospheric backgrounds over inset media cards in marketing heroes.

## Do
- Use for landing / marketing moments and empty-state delight.
- Gate heavy effects behind `prefers-reduced-motion`.

## Don't
- Don't sprinkle spotlight/glow on every dashboard card.
- Don't use purple-on-white gradient clichés by default.
