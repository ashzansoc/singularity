# Tremor — Analytics dashboards

Best used for: KPI cards, area/bar/line charts, trackers, dashboards.

## Patterns
- KPI row → chart → table hierarchy.
- One job per section; avoid packing stats into the hero.
- Neutral backgrounds; restrained accent for series colors.

## Do
- Use for CSV analytics, SaaS metrics, admin insights.
- Pair with shadcn Table for drill-down.

## Don't
- Don't put a chart collage in the first viewport of a marketing page.
